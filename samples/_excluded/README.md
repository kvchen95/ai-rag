# 暂不入库的样本

这里的 PDF 会被扫描器跳过（`api/ingest/fingerprint.py` 的 `iter_sample_paths`
约定：`_` 开头的目录整棵不进扫描）。放进来是"留着但不参与评测"的唯一动作，
不需要改配置。

| 文件 | 为什么不入库 |
|---|---|
| `中芯国际机构调研纪要.pdf` | PDF 结构损坏（`/'Producer', b'PyPDF2'` 字典非法），pdfplumber 打不开。修好或换一份可用版本后再移回 `pdf_reports/` |
| `【财报】中芯国际：中芯国际2024年年度报告.pdf` | 222 页扫描件，首页仅 79 字符文字层。跑 OCR 需十几分钟且识别质量未知，一期不纳入评测 |

年报单独作为"OCR 链路验证"样本使用，不与黄金集混跑——混在一起时，
OCR 识别错误会污染"数值准确率"这个指标，让人分不清是检索错了还是识别错了。
